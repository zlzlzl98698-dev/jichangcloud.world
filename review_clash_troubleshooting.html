二、十大高频核心故障场景与处置 SOP

  1. 节点全部超时 Timeout / 9999ms：系统时间偏差、测速探针失效、出口 IP 轮换、UDP QoS 阻断；
  2. 节点测速全绿但浏览器打不开网页：系统代理未勾选、SwitchyOmega 插件冲突、Fake-IP 死锁；
  3. 退出 Clash 后电脑彻底断网：注册表未复位清零机制、一键注册表修复命令；
  4. 提示 `bind: address already in use` 端口冲突：任务管理器清理、CMD `netstat` 查 PID 强杀与端口避让；
  5. 国内微信朋友圈发不出图片、网页变慢：误开全局模式排查、`qpic.cn` 与 `GEOIP,CN,DIRECT` 直连配置；
  6. TUN 模式启动报错 Service Error：管理员提权、Wintun 驱动修复、gVisor 协议栈容灾；
  7. Windows 商店 / Netflix UWP 报错 0x800704cf：微软沙盒回环隔离一键豁免工具实操；
  8. 订阅更新报 403 Forbidden / Rate Limited：频控冷却、更新间隔科学调整（12~24小时）、UA 伪装；
  9. 终端 CMD / Git / Docker 无法翻墙：TUN 物理接管 vs 环境变量注入；
  10. 局域网 NAS / 打印机无法访问：私有网段 IP-CIDR 直连与 `no-resolve` 参数防 DNS 污染。
