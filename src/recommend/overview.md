# 科学上网入门科普：小白也能看懂的网络代理全解析

<div class="answer-first-callout">
  <strong>核心结论（Answer-First）：</strong><br />
  科学上网的核心原理在于：通过一台位于境外的代理中转服务器，将用户受防火墙阻断的请求通过高强度加密方式传输过去，再由境外服务器代为访问并返回数据。目前主流的代理协议包括 Shadowsocks、Trojan 与 VLESS，配合 Clash Verge 或 Shadowrocket 等客户端实现规则分流。
</div>


## 一、核心术语通俗解释

1. **防火长城 (GFW)**：中国国家级互联网审查过滤系统，通过 DNS 污染、TCP 重置、IP 黑名单及基于深度包检测 (DPI) 的特征识别来阻断对海外特定网站的访问。
2. **机场 (Airport)**：指批量提供多条海外代理线路并以“订阅链接”形式分发给用户的商业服务商（因早期客户端图标为纸飞机而得名）。
3. **订阅链接 (Subscription URL)**：包含几十个海外节点连接参数的一串加密网址，粘贴进客户端即可自动同步全部节点列表。
4. **规则分流 (Rule-based Routing)**：根据访问的目标域名智能分流——访问国内网站（如百度、淘宝）走本地直连不消耗流量；访问海外受阻网站（如 Google、YouTube）自动走代理节点。
