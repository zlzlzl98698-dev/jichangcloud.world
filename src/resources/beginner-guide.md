## 极简 5 分钟新手配置清单

```
第一步：选购套餐 (建议先买月付，体验稳定再续费)
  └── 推荐品牌：光速云 (综合第一) / 飞猫云 (小白自研端)

第二步：根据您的设备准备客户端
  ├── Windows 电脑：下载【Clash Verge Rev x64-setup.exe】并安装
  ├── Mac 苹果电脑：下载【Clash Verge Rev aarch64.dmg】(M芯片)
  ├── iPhone 苹果手机：美区 App Store 购买【Shadowrocket (小火箭)】
  └── Android 安卓手机：下载安装【v2rayNG.apk】或【FlClash.apk】

第三步：一键导入并开启
  ├── 登录机场后台，点击“一键导入”或“复制订阅链接”
  ├── 粘贴进客户端的订阅管理中
  └── 选择一个延迟较低的节点，打开“系统代理”开关！
```
